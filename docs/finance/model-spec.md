# 재무 모델

단위는 **백만 원 정수**다. 화면은 억 원과 조 원으로 포맷한다. 부동소수로 돈을 쌓지 않는다. 이 문서는 게임 규칙이다. 회계 기준의 완전 구현도, 투자 자문도 아니다.

v1의 생성기는 아래 항목의 부분집합으로 이미 분기 자료를 만든다. 자리표시자 파라미터이며 공시에 적합하지 않았다. `tools/datagen/`.

## 손익계산서

분기.

| 항목 | 식 |
| --- | --- |
| 매출 | 전기 매출 × (1 + 성장률) |
| 매출원가 | 매출 × (1 − 매출총이익률) |
| 매출총이익 | 매출 − 매출원가 |
| 판관비 | 매출 × 판관비율 |
| EBITDA | 매출총이익 − 판관비 |
| 감가상각 | 기초 순유형자산 × 분기 상각률. 생성기는 이 단순식을 쓴다 |
| EBIT | EBITDA − 감가상각 |
| 이자비용 | 기초 차입금 × 연이자율 / 4 |
| 세전이익 | EBIT − 이자비용 |
| 법인세 | max(세전이익, 0) × 실효세율. 이연법인세는 v1에서 만들지 않는다 |
| 당기순이익 | 세전이익 − 법인세 |

성장률, 마진, 판관비율은 회사의 구조 파라미터에 작은 분기 충격을 더한 값이다. 충격은 시드된 난수이며, 주가 경로가 아니다.

빠진 것, 일부러: 지분법, 중단사업, 기타포괄, 주식보상비용의 별도 행. 필요해지면 EBITDA 정의에 다시 넣는다. 게임의 EBITDA는 상각 전 영업이익으로 고정한다.

## 재무상태표

| 자산 | 부채와 자본 |
| --- | --- |
| 현금 | 매입채무 |
| 매출채권 | 차입금 |
| 재고 | 자본금 |
| 순유형자산 | 이익잉여금 |

순유형자산 = 총유형자산 − 감가상각누계액.

운전자본 일수:

- 매출채권 = 매출 × DSO / 90
- 재고 = 매출원가 × DIO / 90
- 매입채무 = 매출원가 × DPO / 90

항등식: 자산 합계 = 부채 합계 + 자본 합계. 생성기가 이를 어기면 출력을 버린다.

v1 이후 행: 리볼버와 정기 대출의 분리, 리스 부채, 충당금, 우선주, 비지배지분, 영업권. 영업권은 인수 시점의 매수차액으로만 생긴다. 영업권을 상각해 EBITDA를 만들지 않는다.

## 현금흐름표

| 항목 | 식 |
| --- | --- |
| 영업 | 당기순이익 + 감가상각 − 운전자본 증감 |
| 투자 | −캡엑스 |
| 재무 | 차입 − 상환 − 배당 |
| 현금 증감 | 셋의 합 |
| 기말 현금 | 기초 현금 + 현금 증감 |

이익잉여금 기말 = 기초 + 당기순이익 − 배당.

캡엑스 = 매출 × 캡엑스 비율. 총유형자산은 캡엑스만큼 늘고, 누계액은 감가상각만큼 늘어 순액이 남는다.

최소 현금을 지키지 못하면 상환을 줄이고, 그래도 부족하면 차입한다. 배당은 당기순이익이 양수이고, 레버리지가 업종 한도 안이며, 최소 현금이 남을 때만 나간다. 이것이 v1 생성기의 재무 정책이다. 플레이어의 배당 리캡은 별도 이벤트다.

## 모델 배수

거래가 없는 분기의 출력은 가격이 아니다.

```
rate_factor = 1 / (1 + rate_beta × (policy_rate − neutral_rate))
cycle = 1 + amplitude × sin(2π × quarter_index / 16)
model_multiple = clamp(base × rate_factor × quality × cycle, floor, cap)
model_ev = round(ebitda × model_multiple)
```

- `base`는 회사를 만들 때 섹터 분포에서 한 번 뽑는다.
- `quality`는 v1 생성기에서 1이다. 게임에서는 마진, 성장, 고객 집중, 설비 연령으로 0.8–1.2 사이를 움직인다.
- `cycle`은 4년 주기의 느린 섹터 파도다. 랜덤 워크가 아니다.
- `policy_rate`와 `neutral_rate`는 시대의 파라미터다. 샘플은 3.5%와 2.5%이며, 한국은행 시계열에 적합하지 않았다.
- `rate_beta`, `amplitude`, `floor`, `cap`은 섹터 파라미터다. 전부 자리표시자다.

순차입금 = 차입금 − 현금. 모델 지분가치 = 모델 EV − 순차입금. 소수 지분과 우선주의 청산 우선권은 그로스 딜에서 이 지분가치를 다시 나눈다.

위원회 마크는 이 모델 지분가치에 보유 지분율을 곱한 값이다. 화면에 “마크”라고 쓰고 “가격”이라고 쓰지 않는다.

## 거래 가격

청산 가격은 이벤트가 만든다. 경매, IPO, 전략적 매각, 세컨더리, 법원 매각.

입찰 가격은 모델 EV에서 출발해 경쟁, 확실성, 실사 발견, 매도자의 인내에 밀린다. 성사된 뒤에만 그 가격이 거래 대장에 남는다. 결렬된 입찰은 가격의 역사가 아니라 협상 로그다.

진입 배수와 엑시트 배수를 나눠 저장한다. 수익의 분해는 나중에 세 조각이다. 배수 변화, 디레버리징, EBITDA 변화. v1 화면은 MOIC와 연율 IRR이면 충분하다.

## LBO

현금 없는, 부채 없는 거래를 기본으로 한다. 예시는 백만 원, 자릿수를 보이기 위한 것이다.

매수 EV 70,000 (EBITDA 10,000 × 7.0). 수수료 1,000. 사용 합계 71,000.

| 조달 | 금액 |
| --- | --- |
| 선순위 정기 대출 | 40,000 |
| 메자닌 | 6,000 |
| 경영진 롤오버 | 2,500 |
| 스폰서 지분 | 22,500 |
| 합계 | 71,000 |

트렌치 규칙:

- **리볼버.** 약정 한도. 미인출 수수료. 운전자본과 최소 현금이 끌어 쓴다. 선순위.
- **TLA.** 분기 의무 상환. 낮은 스프레드. 코버넌트가 두껍다.
- **TLB.** 의무 상환이 작고 스프레드가 높다. 현금 스윕의 대상이 된다.
- **메자닌 또는 홀드코 PIK.** 현금 이자가 부족하면 원금이 불어 난다. 후순위. 지분 키커는 v1에서 단순 비율로 둔다.

현금 스윕: 최소 현금을 남긴 뒤의 초과 현금으로 선순위 원금을 갚는다. 배당보다 앞선다. 코버넌트 위반 중에는 스윕이 의무가 되고 배당은 멈춘다.

코버넌트 두 개로 시작한다.

- 레버리지: 순차입금 / 연환산 EBITDA ≤ 한도
- 이자보상: 연환산 EBITDA / 현금 이자 ≥ 한도

한도는 트렌치 약정에 숫자로 있다. 위반의 플레이는 `covenant_breach` 이벤트다.

배당 리캡: 새 차입의 조달로 사용(배당)을 맞춘다. 레버리지가 올라가고, 지분 현금이 들어온다. IC 안건이다. 리캡 직후 배수는 거래 가격이 아니다. 새로 생긴 것은 배당 금액이다.

수익:

- 스폰서 MOIC = 엑시트 때 스폰서에게 남는 현금 / 납입 지분
- IRR은 분기 현금흐름(납입, 배당, 엑시트)의 내부수익률을 연율로 바꾼 값이다. 빈 분기에도 현금흐름 0을 넣어 기간을 유지한다.

엑시트 예시를 이어서 보면, 5년 뒤 EBITDA 13,000, 엑시트 배수 6.5, EV 84,500, 순차입금 22,000, 지분가치 62,500. 스폰서 지분 90%면 56,250. 납입 22,500 대비 MOIC 2.5배. 이 경로는 교재용 산수이며 생성기 출력이 아니다.

경영진 롤오버는 보통주 비율로 남는다. 스윗 에쿼티는 MIP 이벤트의 조건으로 나중에 나눈다.

## 부실 워터폴

게임 규칙의 단순 순위다. 채무자 회생법의 조문을 베끼지 않았고, 법정 조언을 대체하지 않는다.

회수 재원은 스토킹 호스 또는 경매가 만든 **매각 대금**과, 담보로 묶인 자산의 담보 가치다.

1. 담보부 채권은 그 담보 가치까지만 우선한다. 넘는 금액은 무담보로 내려간다.
2. 그 다음 우선변제 바구니. 게임에서는 “법정 우선” 한 줄로 묶는다. 임금과 조세의 실제 순위를 조문 단위로 나누지 않는다.
3. 무담보 금융채권.
4. 상거래 채권.
5. 후순위와 주주. 주주는 위의 바구니가 가득 찬 뒤에만 남는다.

각 바구니는 재원이 바닥나면 안분한다. 플레이어가 사는 것은 보통 무담보 채권이거나, 매각 절차의 인수인 지분이다. 채권 매입 가격과 워터폴 회수액의 차이가 그 플레이의 성과다.

스토킹 호스에는 최소 입찰 증액과 브레이크업 비용이 있다. 브레이크업 비용은 매각 대금에서 빠지고, 그래서 후순위 회수를 줄인다. 플레이어가 호스가 되면 그 비용을 받을 수 있으나, 더 높은 입찰이 나오면 회사를 잃는다.

DIP에 해당하는 신규 자금은 워터폴 최상단의 짧은 바구니로 둔다. v1 구현 범위 밖이고, 부실 딜을 열 때 이 순서를 유지한다.

## 검증

분기가 저장되려면 다음이 참이다.

- 자산 = 부채 + 자본
- 기말 현금 = 기초 현금 + 현금 증감
- 이익잉여금의 증감 = 당기순이익 − 배당
- EBITDA = 매출총이익 − 판관비
- 티커 필드가 없고, 주가 필드가 없다
