# 오디오

음원 파일은 저장소에 넣지 않는다. 트랙을 고르면 라이선스 문장과 고지 여부를 크레딧에 적는다.

## Kenney 오디오

- 목록의 Audio 분류: <https://kenney.nl/assets>
- 라이선스: 무료 팩 페이지가 CC0라고 밝히는 흐름은 [그림](art-and-ui.md)과 같다. 오디오 팩 페이지에서도 같은 문장을 확인한다.
- 이유: UI 클릭, 짧은 징글. 최종 믹스의 음악으로 바로 쓰지 않아도 자리표시자로 충분하다.

## Sonniss GDC 번들

- 주소: <https://sonniss.com/gameaudiogdc>
- 조건: 게임 등 미디어 제작용 로열티 프리. 크레딧은 필수가 아니라고 페이지가 적는다. 효과음 자체의 재판매와 AI 학습은 금지라고 적는다. 연도별 Read the License를 따른다. OSI 라이선스 이름이 아니다.
- 이유: 공장, 창고, 회의실의 효과음. 용량이 크므로 고른 파일만 나중에 패키지에 넣는다.

## Kevin MacLeod / Incompetech

- FAQ: <https://incompetech.com/music/royalty-free/faq.html>
- 조건: 저작자 표시가 필요하다. 정확한 고지 문장은 FAQ의 현재 문장을 복사한다.
- 이유: 하우스 테마의 임시 음악. 표시를 빼는 순간 쓸 수 없다.

## FreePD

- 주소: <https://freepd.com/>
- 조건: 퍼블릭 도메인 음원이라고 사이트가 안내하는 모음이다. 트랙 페이지의 고지를 읽고, 의심스러우면 쓰지 않는다.
- 이유: 표시 의무가 없는 임시 음악의 후보.

## Freesound

- FAQ: <https://freesound.org/help/faq/>
- 조건: 계정과 트랙별 라이선스. CC BY, CC0, 샘플링 금지 등이 섞여 있다.
- 이유: 특정 기계음. 라이선스가 CC0이거나 표시 문장을 우리가 지킬 수 있는 것만.

## jsfxr

- 저장소: <https://github.com/chr15m/jsfxr>
- 웹: <https://sfxr.me/>
- 라이선스: 이 점검에서 저장소 LICENSE 본문은 열지 않았다. 생성기를 재배포하기 전에 읽는다.
- 이유: 아주 짧은 UI 음을 직접 만들어, 제3자 파일을 아예 피하고 싶을 때.

게임의 기본 음량은 낮다. 지도 위의 공장은 루프 소음으로 화면을 채우지 않는다. 이벤트(파업, IC, 경매)만 짧게 변한다.
