# 범위와 로드맵

## 잠그는 것

- 싱글 플레이. 계정, 서버, 멀티플레이가 없다.
- 오프라인. 릴리스 빌드는 네트워크 없이 저장하고 진행한다.
- 콘텐츠는 빌드에 포함된 로컬 DB다. 파이프는 `공개 통계 → 산업 분포 → 시드 생성기 → 검증 → content.sqlite`.
- 언어는 한국어가 1차다. 식별자와 수식은 영어다.

## v1에 있는 것

| 항목 | 범위 |
| --- | --- |
| 시대 | 2024–2026 고금리 한 시대 |
| 모드 | 커리어 하나. 하우스 선택 없음 |
| 하우스 | TMSS Partners, 플레이어는 VP, 펀드는 Fund III |
| 지도 | 대한민국. 해외 법인과 해외 딜 없음 |
| 섹터 | 식품 제조, 산업 부품, 냉장·창고 물류. 제안이며 생성기 파라미터와 같다 |
| 회사 | 가공 약 40개. 각 회사는 분기 3제표 |
| 딜 | 바이아웃 하나가 소싱부터 클로징까지. 다른 스펙트럼은 데이터만 준비 |
| IC | 상정, 파트너 반응, 가부. 재량 한도는 VP에게 거의 없다 |
| 이벤트 | 카탈로그 36개 중 12개 |
| 인수 후 | 가격, 캡엑스, 인력, 비핵심 매각 |
| 저장 | 로컬 SQLite. 목록은 인덱스가 있는 카드 페이지. 세이브도 로컬 파일 |

40개와 12개는 목표 개수다. 생성기가 검증을 통과한 개수만큼 들어간다.

## v1에 없는 것

- 하우스 선택, 다른 시대(저금리, 위기, 1990년대)
- 해외 지도
- 플레이어블 그로스·VC·부실의 전체 캠페인. 규칙은 스펙에 있고, 콘텐츠 일부가 먼저 들어올 수 있다
- 승진으로 열리는 캐리의 정산 전체. 데이터 필드만 둔다
- 온라인, 리더보드, 모드

## 그 다음

1. 부실 워터폴과 스토킹 호스가 한 딜로 끝까지 간다.
2. 시리즈 B 다운 라운드가 한 딜로 끝까지 간다.
3. 이벤트 나머지. 컨티뉴에이션과 펀드레이징은 하우스 레이어라 딜보다 나중에 붙어도 된다.
4. Principal 승진. 재량 한도와 캐리 포인트가 열린다.
5. 두 번째 시대와 두 번째 지역. 지역은 새 분포와 새 지도 타일이 준비된 뒤에만 연다.

## 콘텐츠 규칙

생성기는 시드로 재현된다. 같은 시드는 같은 회사를 만든다. 릴리스 콘텐츠는 시드와 분포 버전을 메타 테이블에 남긴다.

분포 파라미터는 사람이 리뷰하기 전에는 `placeholder`다. 자리표시자로 만든 회사를 최종 40개라고 부르지 않는다. 표본이 작은 산업(예를 들어 적합에 쓴 실존 회사가 30곳 미만)은 분포로 올리지 않는다. 한 회사의 공시가 그대로 지문이 되지 않게, 생성 결과는 여러 축으로 흔든 뒤 검증한다.

검증이 거절하는 것:

- 실존 그룹·브랜드 문자열이 들어간 이름
- 티커
- 도로명 주소, 실제 사업장 좌표를 소수점 다섯 자리 이상으로 복제한 위치
- 대차대조표가 안 맞는 분기
- 현금흐름과 현금 잔액이 어긋나는 분기
- 이익잉여금이 당기순이익과 배당으로 이어지지 않는 분기

자세한 법적 경계는 [데이터 사용 메모](../legal/data-usage.md)에 있다.
