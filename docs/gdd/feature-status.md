# 구현 상태

첫 플레이 루프다. 숫자는 Rust `sim-core`가 만들고, 화면은 그 결과만 그린다. 아래는 지금 코드 기준이다.

## 구현됨

| 조각 | 상태 |
| --- | --- |
| 화면 | 흰색·검정·카민 `#9B1B30` 하나. 1px 규칙, 직각, 그림자 없음. Pretendard Variable 링크 |
| 홈 | 순자산, 미소진 약정, 납입, IRR, MOIC, DPI, TVPI, 현금, 평판, 뉴스, 할 일 |
| 시작 | III호, 약정 500억(50,000 백만 원). 출자자 다섯. 투자기간 5년, 존속 10년, 관리보수 2%, 허들 8%, 캐리 20% |
| 딜 목록 | 단계, 절차, 희망가, 기한. 지도에는 그 페이지의 핀만 |
| 협상 | 의향, 조건, 투자심의, 구속 입찰, 종료. 증권, 이사, 코버넌트, 드래그, 태그, 어닝아웃 |
| 투자심의 | 파트너 여섯. 과반과 의장의 반대 없음 |
| 공동투자와 차입 | 바이아웃에 전략적 투자자와 단일 차입 |
| 독점 소싱 | 회사 목록에서 접촉. 개방도와 평판이 문턱 |
| 회사 | 개요, 사업장, 경영진, 지분, 분기 제표, 청산 기록, 우리 포지션 |
| 펀드 | 호출, 보수, 비용, 유럽형 워터폴, DPI, TVPI, IRR |
| 평판 | 정수 하나. 분배, 성과, 주총 누락이 움직인다 |
| 인수 후 | 대표 교체, 비용·가격·증설·자산 매각, 이사회, 1분기 주총 |
| 시계 | 멈춘 채로 시작. 1배, 2배, 4배. 13주마다 결산. 애니메이션은 회계를 밀지 않음 |
| 콘텐츠 | 회사 40, 섹터 3, 증권사, 매도자, 출자자, 전략적 투자자, 대주, 대표 후보. 카드는 20개 페이지 |
| 테스트 | 워터폴, LBO 스케줄, 보수, IRR, 분기 항등식 |

장부는 2024년 1분기부터 2025년 4분기까지 여덟 분기다. 플레이는 2026년 1분기 0주에서 시작한다. 그래야 첫 결산이 이미 있는 분기를 덮지 않는다.

가격은 진입과 엑시트의 청산 기록에만 있다. 그 사이 숫자는 EBITDA에 모델 배수를 곱한 마크다.

## 단순화

| 조각 | 지금 |
| --- | --- |
| 시나리오 12개 | 코버넌트, 주총, 보수 호출, 경매 기한, 다음 펀드 가능 여부만 있다. 부정, 파업, 기업결합, 컨티뉴에이션, 다운라운드, 스토킹 호스, 인력 이탈, 어닝아웃 분쟁은 대본이 없다 |
| 워터폴 | 펀드 전체의 유럽형이다. 딜별 워터폴은 없다 |
| LBO | 테스트 스케줄은 선순위와 메자닌이다. 게임의 인수는 시설 하나다 |
| 평판 | 정수 하나. 동종 TVPI는 1.10배로 고정 |
| 뉴스 | 템플릿 id와 최근 16개. 기사 데이터베이스가 아니다 |
| 저장 | 브라우저 `localStorage`. SQLite 세이브는 이 루프에 연결되어 있지 않다 |
| 취득 회계 | 장부 자본을 맞추고, 영업권 계정은 두지 않는다 |
| 신용 | 쿠폰은 회사 결산의 추가 이자다 |
| 다음 펀드 | 가능한 약정만 기록한다. 활성 펀드가 바뀌지는 않는다 |
| 분배 | 약정 비율로 나눈다. 사이드 레터는 없다 |
| 구속 입찰 | 유보가격의 96%가 바닥이다. 경매 모델 전체는 아니다 |
| 산업 파라미터 | 자리표시자다. 공시에 맞추지 않았다 |
| 지도 | 한반도 밑그림이다. 타일 서버를 부르지 않는다 |
| 글꼴 | jsDelivr의 Pretendard 동적 서브셋. 실패하면 고딕 스택 |

## 아직 없는 것

- Tauri 저장 경로가 이 게임 상태에 연결되어 있지 않다.
- `app-commands`는 아직 카드 조회다.
- 시나리오 대본 12개가 모두 들어 있지는 않다.
- Pixi와 Rive는 없다.
- 첫 시뮬 분기의 모델 배수는 생성기가 마지막에 찍은 배수와 한 스텝 다를 수 있다. 대차 항등식은 유지된다.
