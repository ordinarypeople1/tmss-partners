# 손맛

결정과 라이선스 확인은 [ADR 0004](../adr/0004-motion.md)다. 이 문서는 화면에서 무엇을 지키는지 적는다.

## 지금 재생되는 것

회사를 고르면 카드가 스프링으로 들어온다. 선택된 핀은 고리가 `transform: scale`과 `opacity`로 퍼진다. 둘 다 동작 줄이기에서 멈춘다. 카드는 `useReducedMotion()`, 핀은 `prefers-reduced-motion`이다.

탭은 8ms 진동을 시도한다. 동작 줄이기이거나 브라우저에 `navigator.vibrate`가 없으면 호출하지 않는다. 데스크톱 브라우저에서는 보통 아무 일도 없다. 기기 햅틱은 Tauri 플러그인으로 나중에 넣는다. 그 플러그인은 Android와 iOS만 지원하고 Rust 1.90이 필요하다. 지금 툴체인은 1.83이다.

## 프레임

120Hz면 한 프레임이 약 8.3ms다. 손맛은 컴포지터 속성만 쓴다. `transform`, `opacity`. 너비, 높이, 위쪽 위치, 그림자를 애니메이션하지 않는다. 파티클과 딜 클로즈를 PixiJS로 올릴 때도 화면에 있는 핀만 갱신한다. 화면 밖 회사의 이펙트를 돌리지 않는다.

저사양 Android 예산(첫 페인트 3초, JS 힙 80MB, 프로세스 350MB)은 [ADR 0001](../adr/0001-tech-stack.md)에 있다. 효과를 추가하기 전에 그 예산 안에서 한 장면을 잰다.

## 나중에 얹는 레이어

1. PixiJS. 핀 일러스트, 파티클, 딜이 닫힐 때의 짧은 연출. MapLibre 캔버스 위다.
2. Rive. 벡터 상태. 무료 플랜의 스플래시와 퍼블리시 한도를 패키징 전에 다시 확인한다.
3. 길게 누르기. 지도의 드래그, 핀치는 MapLibre가 한다. 그 위에 제스처가 필요할 때만 use-gesture를 넣는다.
4. Tauri haptics. 모바일 패키지를 링크할 때, Rust를 1.90 이상으로 올린 뒤, Android와 iOS 타겟에만.

렌더를 Godot이나 Unity로 바꿔도 시뮬 틱은 Rust 커맨드로 남긴다. 연출이 분기를 진행시키지 않는다.
