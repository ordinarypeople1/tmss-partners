# 시나리오 카탈로그

이벤트의 골격이다. 각 항목은 나중에 트리거, 선택지, 3제표 효과, 에이전트 반응으로 펼친다. v1은 표시된 12개만 구현한다.

공통 필드(구현 시): `id`, 국면(소싱 / 실사 / 체결 / 보유 / 하우스), 관련 에이전트, 플레이어 선택, 재무 효과, 평판 효과, 시간 제한.

## v1 — 12개

| id | 이름 | 국면 |
| --- | --- | --- |
| `auction_war` | 경매 과열 | 소싱 |
| `fraud_after_close` | 클로징 후 부정 | 보유 |
| `refinancing_wall` | 차환의 벽 | 보유 |
| `covenant_breach` | 코버넌트 위반 | 보유 |
| `earnout_dispute` | 어닝아웃 분쟁 | 체결 이후 |
| `strike` | 파업 | 보유 |
| `antitrust_review` | 기업결합 심사 | 체결 |
| `continuation_fund` | 컨티뉴에이션 | 하우스 |
| `down_round` | 다운 라운드와 크램다운 | 그로스 보유 |
| `stalking_horse` | 스토킹 호스 | 부실 |
| `fundraising_roadshow` | 펀드레이징 로드쇼 | 하우스 |
| `team_poaching` | 팀 스카우트 | 하우스 / 보유 |

### auction_war

증권사가 같은 티저를 여러 바이아웃과 전략적 매수자에게 돌린다. 입찰 라운드가 늘고, 독점 협상 기간이 짧아진다. 플레이어는 가격, 확실성(펀딩 아웃의 유무), 속도 중 무엇을 밀지 고른다. 모델 배수와 별개로, 이 자리에서 청산 가격이 생긴다.

### fraud_after_close

재고 또는 매출의 일부가 클로징 뒤에 실재하지 않는 것으로 드러난다. 진술보장 보험과 매도자 유보금이 있으면 협상의 재료가 된다. 없으면 첫 해 EBITDA와 운전자본이 즉시 줄어든다. IC에 언제 보고하는지가 평판을 가른다.

### refinancing_wall

만기가 4분기 안으로 들어온다. 금리가 진입 때보다 높다. 대주는 스프레드와 상각, 추가 지분을 요구할 수 있다. 리파이낸싱에 실패하면 `covenant_breach` 또는 부실 국면으로 넘긴다.

### covenant_breach

순차입금 / EBITDA 또는 이자보상배율이 약정을 넘는다. 에쿼티 큐어는 펀드 잔여 약정과 IC를 소모한다. 웨이버는 수수료와 추가 담보를 요구한다. 방치하면 배당과 추가 인수가 막힌다.

### earnout_dispute

매도자와의 추가 대가 산식에서 매출 인식이나 런레이트가 갈린다. 합의하면 현금이 나가고, 소송으로 가면 시간과 평판이 나간다. 회계 정책 선택이 다음 분기 매출을 실제로 바꾼다면, 그 선택은 이벤트 뒤에 감사 리스크로 돌아온다.

### strike

구조조정 또는 사업장 폐쇄 이후 작업 중지가 난다. 매출이 빠지고, 고정비는 남고, 언론 플래그가 선다. 합의는 비용이고, 대체 인력은 품질과 고객 이탈이다.

### antitrust_review

기업결합 심사. 클로징이 미뤄지고, 시정 조치로 자산 매각이 조건이 될 수 있다. 심사가 길어지면 매도자의 인내와 자금 확약 수수료가 같이 닳는다. v1의 심사는 승인과 조건부 승인, 철회 세 갈래면 충분하다. 특정 위원회의 실제 사건을 재연하지 않는다.

### continuation_fund

Fund II 잔여 자산을 새 비클로 넘기자는 제안. LP마다 팔로온과 현금화 요구가 갈린다. 가격은 제3자 의견과 모델 마크 사이에 있고, 이해충돌은 설민재의 안건이다. 청산 가격이 아니라 **이전 가격**으로 표시한다.

### down_round

포트폴리오 그로스 회사가 다음 라운드를 낮은 밸류에이션에 연다. 크램다운은 기존 지분율을 깎는다. 플레이어는 후속에 참여하거나, 지분을 지키거나, 세컨더리로 일부 판다. v1에서는 바이아웃 펀드 안의 소수 그로스 포지션 하나로 경험하게 할 수 있다.

### stalking_horse

회생 매각에서 최초 입찰자가 될 기회. 브레이크업 비용과 최소 증액 단위가 규칙을 이룬다. 다른 입찰자가 없으면 그 가격이 청산 가격이 되고, 있으면 경매가 열린다. 워터폴 스펙의 회수율이 입찰 한도의 근거다.

### fundraising_roadshow

Fund III의 후속 또는 하우스의 다음 펀드를 위한 미팅. 보유 자산의 마크, 미실현 성과, 분쟁 기사가 LP의 질문을 바꾼다. v1에서는 한 분기의 일정으로 끝내고, 약정 성공과 실패가 다음 해 투자 여력을 바꾼다.

### team_poaching

다른 하우스가 플레이어 팀의 어소시에이트 또는 포트폴리오 CFO를 빼 간다. 보상으로 막으면 펀드 비용 또는 회사 비용이고, 놓치면 진행 중 딜의 실사 속도가 떨어진다.

## 나머지 — 24개

v1 이후. 한 줄은 플레이어가 잃거나 얻는 것이다.

| id | 이름 | 한 줄 |
| --- | --- | --- |
| `dividend_recap` | 배당 리캡 | 추가 차입으로 현금을 빼면 배수와 별개로 지분 현금이 늘고 레버리지가 올라간다 |
| `sale_leaseback` | 세일앤리스백 | 공장을 팔고 임차하면 현금이 들어오고 장기 임차료와 통제권이 바뀐다 |
| `bolt_on` | 볼트온 매물 | 같은 섹터의 작은 회사가 매물로 나오며, 플랫폼의 배수와 통합 위험이 같이 온다 |
| `key_customer_loss` | 핵심 고객 이탈 | 집중도가 높던 매출이 한 분기에 빠진다 |
| `ceo_exit` | 경영진 사임 | 후임 공백 동안 마진과 은행의 시선이 나빠진다 |
| `union_talks` | 단체교섭 | 임금과 고용 안정이 다년 비용이 된다 |
| `environmental_find` | 환경 부채 | 실사에서 빠졌던 토양·폐수 비용이 충당금이 된다 |
| `ipo_window` | 상장 창 | 공모 시장이 열리고, 공모가는 모델 배수와 다른 청산 가격이 된다 |
| `strategic_inbound` | 전략적 매수자 | 동종 기업이 보유 자산을 비공개로 묻는다 |
| `lp_excuse` | LP 엑스키즈 | 출자자가 특정 딜의 참여를 빼며 펀드 잔액이 줄어든다 |
| `key_person` | 키맨 | 파트너 이탈이 약정의 키맨 조항을 건드리며 투자가 멈춘다 |
| `press_inquiry` | 언론 취재 | 구조조정이나 배당 리캡이 기사가 되며 IR이 개입한다 |
| `peg_fight` | 운전자본 펙 | 클로징 정산의 기준 운전자본을 두고 매도자와 다툰다 |
| `mac_clause` | 중대 변경 | 사이닝과 클로징 사이에 실적이 빠져 매수자가 파기를 검토한다 |
| `rate_shock` | 금리 충격 | 변동금리 이자와 모델 배수가 같은 분기에 움직인다 |
| `multiple_compression` | 배수 압축 | 섹터 사이클이 내려가 위원회 마크가 낮아진다. 거래가 없으면 현금은 그대로다 |
| `plant_outage` | 가동 중단 | 화재, 정전, 리콜로 한 분기의 물량이 빠진다. 실존 사고를 재연하지 않는다 |
| `concentration_reveal` | 집중도 발견 | 실사 후반에 한 고객 비중이 티저보다 크다는 사실이 나온다 |
| `mip_talks` | 경영진 인센티브 | 롤오버와 스윗에쿼티의 조건이 클로징 전 협상이다 |
| `integration_miss` | 통합 실패 | 볼트온의 시스템과 영업이 한 해 안에 붙지 않는다 |
| `direct_lender` | 직접 대주 | 은행 신디케이트 대신 사모 여신이 더 빠른 조건으로 들어온다 |
| `founder_secondary` | 창업자 세컨더리 | 창업자가 일부 지분만 현금화하고 남기를 원한다 |
| `license_delay` | 인허가 지연 | 식품·물류의 인허가가 클로징 조건을 민다 |
| `dpi_pressure` | 분배 압력 | LP가 미실현 성과보다 현금 분배를 요구해 이른 엑시트를 재촉한다 |

## 만들지 않는 이벤트

실존 기업의 사고, 실명 인물의 스캔들, 실제 재판의 당사자를 알아보게 하는 사건은 카탈로그에 넣지 않는다. 산업 통계로 잡을 수 있는 것은 빈도뿐이다.
