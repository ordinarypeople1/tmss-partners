# 화면 토큰

밝은 테마가 기본이다. 바탕은 아주 옅은 따뜻한 종이색이고, 글자는 따뜻한 먹색이다. 강조는 하나다. 짙고 채도가 낮은 카민 `#9B1B30`이다.

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--page` | `#F6F3EE` | 페이지 바탕 |
| `--bg` | `#FFFDFB` | 선택된 글자, 카드에 가까운 흰 면 |
| `--surface` | `#FFFDFB` | 카드, 표 |
| `--ink` | `#1C1714` | 본문 |
| `--ink-2` | `#3D352F` | 보조 본문 |
| `--muted` | `#7A7168` | 라벨 |
| `--rule` | `#E6DFD6` | 구분, 입력 테두리, 알약 트랙 |
| `--rule-strong` | `#1C1714` | 강한 구분 |
| `--grey` | `#8D847A` | 비활성 글자, 지도 행정 경계 |
| `--grey-2` | `#D5CDC3` | 시트 손잡이 |
| `--accent` | `#9B1B30` | 주요 동작, 핵심 숫자, 포커스, 살아있는 딜 |
| `--accent-wash` | `rgba(155, 27, 48, 0.08)` | 토큰만 둔다. 카드 배경으로 쓰지 않는다 |
| `--on-accent` | `#FFFDFB` | 카민 위의 글자 |
| `--glass` | `rgba(255, 252, 248, 0.72)` | 떠 있는 층 |
| `--highlight` | `rgba(255, 255, 255, 0.72)` | 면 위쪽 1px 하이라이트 |
| `--r-sm` | `10px` | 버튼, 입력, 핀 |
| `--r-md` | `14px` | 목록 카드, 숫자 카드 |
| `--r-lg` | `20px` | 히어로, 상단 바, 알약 |
| `--r-xl` | `28px` | 아래 탭, 시트 |

깊이는 세 단이다. 페이지 바탕, 그 위의 카드, 그 위의 유리층. 카드 그림자는 따뜻한 갈색을 아주 낮게 두 겹으로 깔고, 위쪽에 흰 1px을 넣는다. 목록의 한 줄은 카드보다 얕다. 유리층은 상단 바, 아래 탭, 지도 위 메모, 시트와 배너뿐이다. `backdrop-filter`로 채도를 조금 올리고 흐리게 한다. 브라우저가 흐림을 모르면 불투명한 면으로 돌아간다.

숫자 카드가 올라오는 스켈레톤만 아주 옅은 가로 반짝임을 쓴다. 그 외 장식 그라데이션은 없다. 이익과 손실을 녹색과 적색으로 나누지 않는다. 보통 숫자는 먹색이고, 손실과 핵심 숫자는 카민이다.

움직임은 transform과 opacity만 쓴다. 카드와 버튼은 눌리면 0.97로 줄어들고, 카드는 포인터에서 2px 떠오른다. 목록은 조금 늦게 들어오고, 목록과 상세는 같은 면을 공유한다. 시계 속도는 알약 안에서 먹색 인디케이터가 미끄러진다. 필터 시트는 손잡이를 끌어 내린다. KPI는 정수로 올라가며 센다. 살아있는 딜 핀은 카민 고리가 한 번 퍼진다. 해와 달은 바뀌며 돈다. `prefers-reduced-motion`이면 이 움직임을 끈다.

화면 모드는 해 또는 달 버튼이다. 처음에는 시스템 설정을 따른다. 고르면 이 브라우저의 `localStorage`에 남는다. 어두운 바탕은 `#12100E`, 면은 `#24211D`, 글자는 `#F6F1EA`다. 카민은 같다. 유리층은 `rgba(28, 25, 22, 0.78)`이다.

글꼴은 Pretendard Variable의 동적 서브셋이다. 파일을 저장소에 넣지 않고 링크만 둔다.

`https://cdn.jsdelivr.net/npm/pretendard@1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css`

큰 제목은 자간을 더 좁히고 줄높이를 1.15에서 1.3 사이에 둔다. 아이콘은 16, 20, 24이고 선 굵기는 1.5에서 1.75다. 아이콘과 글자 사이는 6px에서 8px이다. 누르는 면은 44px 이상이다. 숫자는 `tabular-nums`다. 긴 한국어 이름은 두 줄에서 자른다. `white-space`로 한 줄을 강제하지 않는다. 한국어 줄바꿈은 `word-break: keep-all`이고, 긴 토큰은 `overflow-wrap: break-word`로 넘긴다. 포커스는 카민 2px, 바깥 3px이다.

Pretendard는 SIL Open Font License다. 출처는 <https://github.com/orioncactus/pretendard>. CDN이 없으면 Apple SD Gothic Neo, 그다음 Malgun Gothic이다.

스토리북은 같은 `styles.css`를 읽는다. 높이와 움직임은 Motion 스토리에 모아 둔다.
